6: Time series at a single point: [x = 50, y = -20]

plot/X=50/Y=-20/T=1:300 ETAN   o==or==o 	plot/T=1:100 ETAN[X=50, Y=-20]



7: Mean over time: 	let ssh_mean = ETAN[T=@ave]
			fill/X=48:52/Y=-22:-20 ssh_mean



8: Anomaly:	let ssh_mean = ETAN[L=@ave]
		let ssha = ETAN - ssh_mean
		fill/X=48:52/Y=-22:-20/T=1 ssha



9: as Zd000001=1 => only one step so don't need to specify but still we can
		   write like that:
			
			fill/X=48:52/Y=-22:-20/L=1/Zd000001=1 ETAN




o== NOTE ==o

1: fill / shade -> 2d maps(fix T) for 3d dataset

2: plot -> 1d lines (fix x and y)

3: @ave, @std -> average and statistics
